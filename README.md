# Express Book Reviews

Final project for the IBM Developing Back-End Apps with Node.js and Express course.

The API supports public book searches, user registration and login, and authenticated review creation, modification, and deletion. It also includes Promise/async-await implementations using Axios for the asynchronous assessment tasks.

## Run the project

```bash
cd final_project
npm install
npm start
```

The server runs at `http://localhost:5000`.

## Submission evidence

The `submissions` directory contains the cURL commands and verified JSON outputs requested by the final assessment.
